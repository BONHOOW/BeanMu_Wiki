# BeanMuWiki — 로고 가이드 (한 장)

## 1. 로고
- **아이디어**: 원두에 꽂힌 책갈피. 기록해 둔 항목(entry)으로서의 원두 — Bean + 위키.
- **버전**: 심볼 단독(기본) · 가로 락업(심볼 + BeanMuWiki) · 소형 컷(16~32px용, 틈이 두껍고 리본이 큼)
- **파일**: `docs/logo/beanmuwiki-symbol.svg`(마스터) · `beanmuwiki-symbol-small.svg`(소형 컷) · `dist/` 안의 black / white / mono / square / favicon / app-icon 변형과 PNG · `appicon/AppIcon-1024.png`(Xcode 원본)

## 2. 여백
심볼 주위에 **리본 너비(마스터 기준 40단위, 심볼 높이의 약 1/5)** 만큼 빈 공간을 둔다. 로고 크기에 비례하고, 고정 픽셀로 두지 않는다.

## 3. 최소 크기
| 버전 | 화면 | 인쇄 |
|---|---|---|
| 심볼(마스터) | 32px | 8mm |
| 심볼(소형 컷) | 16px (`-favicon`, 웹 아이콘 세트) | 5mm |
| 가로 락업 | 120px 너비 | 30mm |

## 4. 색
| 이름 | HEX | 용도 |
|---|---|---|
| 브랜드 그린 | `#2F6B45` | 흰·크림 바탕의 단색 로고, 앱 아이콘 타일 |
| 크림 | `#FAF9F5` | 그린 타일 위의 마크, 다크 모드 반전 |
| 잉크 | `#141413` | 흑백 인쇄 |

**허용 조합**: 그린 마크 on 흰/크림 · 크림 마크 on 그린 · 검정 on 흰 · 흰 on 검정. 사진 위에는 흰 또는 검정 단색을 차분한 영역에.
그라디언트·그림자·테두리를 더하지 않는다 (예전 에메랄드 그라디언트 타일은 폐기).

## 5. 서체
- 락업 워드마크: 시스템 산세리프 볼드(SF Pro Display / Helvetica Neue), 자간 −3%. 앱 안 타이포는 `Theme.swift` 규칙을 따른다.

## 6. 하지 말 것
늘리거나 찌그러뜨리지 않기 · 팔레트 밖 색으로 바꾸지 않기 · 회전하지 않기 · 리본이나 틈을 따로 옮기거나 지우지 않기 · 복잡한 배경 위에 컨테이너 없이 올리지 않기 · 워드마크를 타이핑해서 다시 만들지 않기.

## 7. 유래
2026-10-09 로고 리디자인 2회차. 컨셉 3종(Sapling / Bookmark / Bracketed) 중 사용자가 **B · Bookmark Bean**을 선택. 이전 아이콘(에메랄드 그라디언트 + 새싹 원두)의 초록 계열과 원두 실루엣은 이어받고, 새싹은 책갈피로 바꿨다. 구성 스크립트: `docs/logo/build_mark.py` (매개변수: 틈 너비, 리본 배율).
